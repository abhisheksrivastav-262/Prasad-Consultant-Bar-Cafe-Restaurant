# Prasad Bar Cafe Restaurant Consultant

Premium multi-page website built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion and Lucide.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build / production

```bash
npm run lint
npm run typecheck
npm run build
npm run start
```

## Deploy

Prepared for Vercel deployment. Set `NEXT_PUBLIC_SITE_URL` to the production domain.

## Notes

- All business images/videos copied from the supplied Downloads folder into `public/assets`. Originals untouched.
- Logo cropped from `logo.jpeg` (extra margins removed) into `public/assets/logo.png`.
- Contact and staffing forms open WhatsApp with a prepared, URL-encoded summary; they do not store data on a server.
